# Documentation Assets

## Dashboard Screenshot

To add a dashboard screenshot:

1. Access your running UniFi Documenter web interface (e.g., http://localhost:8080)
2. Take a screenshot showing:
   - The header with GitHub logo and version info
   - Current job progress (if running)
   - Generated files list
   - Job history section
3. Save as `dashboard-screenshot.png` in this directory
4. Recommended size: 1200x800px or similar

## Example Screenshot Content

The screenshot should show:
- ✅ Modern gradient header with UniFi Documenter logo
- ✅ GitHub icon link in header
- ✅ Version and build information
- ✅ Current job status with progress bar
- ✅ Document processing stats (total, processed, current group)
- ✅ Generated files list with clickable links
- ✅ Batch progress indicator
- ✅ Professional, clean UI design
